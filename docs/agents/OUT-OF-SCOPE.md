# Out-of-Scope 知识库

记录已经评估并拒绝的方案，避免未来重复讨论。

## 格式

每个条目包含：
1. **被拒绝的方案** — 一句话描述
2. **拒绝时间** — YYYY-MM-DD
3. **拒绝原因** — 核心论据
4. **相关 issue / PR** — 如有

## 示例条目

```markdown
### 引入 Celery 替代 APScheduler

- **拒绝时间**: 2026-05-01
- **拒绝原因**: 当前调度任务量小（<100/天），APScheduler 轻量足够；引入 Celery 需要 Redis + Worker 进程，运维成本不划算
- **相关**: ISSUE-042
```
