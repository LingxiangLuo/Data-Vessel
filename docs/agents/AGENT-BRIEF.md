# Agent Brief 写法规范

Agent brief 是 issue 的精简描述，用于 `/triage` 分类时快速理解需求。

## 格式

```markdown
## 一句话描述
<20 字以内的核心诉求>

## 影响范围
- 前端 / 后端 / 部署 / DQC / DSL
- 哪些模块会变动

## 验收标准
- [ ] 标准 1
- [ ] 标准 2

## 已知限制
- <假设或约束>
```

## 示例

```markdown
## 一句话描述
为工作流列表添加标签过滤功能

## 影响范围
- 后端: `workflow.py` list_workflows
- 前端: Workflow.vue 筛选区域

## 验收标准
- [ ] 支持按多个标签同时过滤
- [ ] 标签从数据库读取，不是写死的
- [ ] 过滤结果支持分页

## 已知限制
- 不涉及标签的创建/编辑（已有独立页面）
```
